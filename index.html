Stuck? Common reasons capture doesn't auto-fire
  • You haven't dragged the bookmarklet to your bookmarks bar yet — see Flow C below.
  • The site uses Cross-Origin-Opener-Policy: same-origin (Google, GitHub, banking sites) which severs the link to this tab. The bookmarklet falls back to clipboard automatically — click Paste from clipboard above.
  • You ran the bookmarklet on a different tab. Use Flow C's Paste from clipboard & render.
  • Pop-ups are blocked. Allow pop-ups for this page and try again.

Fetch via proxy

public / SSR pages

Routed through public CORS proxies with automatic fallback across 8 services. Best for static / server-rendered pages without authentication. Press Render at the top to use this flow.

Advanced: custom proxy

Tried before the public proxies. Use {url} as the placeholder, or end with = / ? / / to append. Saved in localStorage. The last successful proxy is also cached and tried first on the next fetch.

XPath Studio URL (embedded in bookmarklet)

The bookmarklet knows this URL. When you click it on any page, it opens XPath Studio and sends the HTML automatically. If you move XPath Studio to a different URL, re-create the bookmark.

How does it work?

Browser security (the same-origin policy) prevents this page from reading cookies or fetching authenticated content from another domain. The bookmarklet runs a small script inside the target tab, reads document.documentElement.outerHTML, and sends it to XPath Studio via postMessage.

Smart auto-detection

  1. Click Go — we first try loading the site directly in the preview.
  2. If the site allows iframe loading: interact with it live, then click Freeze & Pick.
  3. If the site blocks iframes (most do): we auto-detect this within 3 seconds and offer two fallbacks:
    • Open in new tab — uses your cookies/login. Best for authenticated pages.
    • Fetch via proxy — grabs static HTML. Best for public pages.
